NAME

rralex - platform architect, DevSecOps lead, free-software tinkerer

SYNOPSIS

rralex [--platform] [--kubernetes] [--linux] [--secops] [--iac] [--observe] [--cloud] [--llm] [--lead] problem ...

DESCRIPTION

rralex designs, builds and runs the platforms other teams ship on, and keeps them secure while they grow. Fifteen-plus years across startups and enterprises: Linux fleets, Kubernetes at scale, vulnerability detection pipelines, and edge devices that have to keep working when the network does not.

Trained in both computer science and information science, so equally interested in systems that scale and in information that stays trustworthy over time.

Evaluates new technology by asking why, then what, then how, and skips the hype. Currently exploring LLM infrastructure and agentic workflows.

OPTIONS

--platform
Platform architecture and site reliability: SLOs, capacity planning, incident management, on-call, cost optimization.
--kubernetes
Managed and self-hosted clusters (EKS, GKE, kubeadm, k3s); containerd, Podman, Docker, Helm, etcd.
--linux
Debian, Ubuntu, RHEL. Kernel tuning, cgroups, namespaces, seccomp, capabilities, eBPF.
--secops
Zero trust, applied cryptography, netfilter, VPNs, TLS, GPG, Vault. Vulnerability detection at scale.
--iac
Ansible, Terraform, Packer, Consul; CI/CD on GitHub and GitLab. Bash, Python, Go.
--observe
Prometheus, Grafana, Datadog, Elasticsearch, Fluentd; PostgreSQL, MySQL, Redis, RabbitMQ.
--cloud
AWS, Google Cloud, Azure, OpenStack.
--llm
LLM infrastructure and agentic workflows: vLLM, Ollama, llama.cpp; Claude, Gemini and local models.
--lead
Leading and mentoring teams, project management, agile delivery, vendors and stakeholders, FOSS governance and compliance.

EXAMPLES

rralex --secops --platform edge-appliance
Designed a virtual appliance that customers run inside their own networks, calling home over a dedicated VPN so a cloud scanning platform can reach what it cannot see. Hundreds of sites.
rralex --linux --iac fleet-upgrade
Moves a fleet of field devices off an aging vendor-built OS onto reproducible in-house images: a card-image factory that builds and self-enrolls a device with no board on the desk.
rralex --secops recovery
Replaced one shared root password with per-device credentials that work offline. Released as breakglass(1).
rralex --llm agentic-ops
Runs infrastructure work with AI coding agents: plan first, tests before code, a fresh reviewer at the end, and guardrails that keep the agent away from production.

PROJECTS

breakglass(1)
Per-device recovery credentials for a device fleet, derived rather than stored. Every device gets its own recovery password, computed from one master key, so a card pulled from one device opens nothing else. Go, HKDF-SHA256, OIDC. Apache-2.0.
TMC2130_PCB
A breakout board that moves a 3D printer's TMC2130 stepper drivers to SPI mode. Open hardware, CC BY-SA 4.0.
bash
Shell scripts, utilities and the occasional joke.

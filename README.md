# rralex.github.io

Source of https://rralex.github.io: a single static page, written as the manual page `rralex(7)`.
No build step and no third-party requests; open `index.html` in a browser to preview it.

The typeface is [Iosevka](https://github.com/be5invis/Iosevka), subset to Latin and served from
`fonts/`, under the SIL Open Font License 1.1 (see `fonts/LICENSE.txt`).
